# Release preparation

The package is TEST38, not an already published stable release. Run UPDATE-GITHUB.cmd -Preview from the extracted package root. The included Windows updater reads GitHub's current stable version, generates the next version, compares against the previous stable tag and regenerates release documentation. If latest is still 1.0.0, the default patch increment is 1.0.1. No release number is hardcoded here.

PACKAGE_NOTES.md is the consolidated human-readable change list consumed by Find-PackageNotes in the updater. CHANGELOG.md retains the 1.0.0 history and a pending development entry. The updater adds the actual stable-version entry at publication time. README and RELEASE_NOTES are also regenerated by the existing workflow.

The supplied updater has compatibility corrections: accept TEST version strings containing a space, synchronize VER_MAJOR/VER_MINOR/VER_PATCH, clear DEV_BUILD for a stable build, delimit an interpolated label before a Markdown colon, emit exactly one UTF-8 BOM so Windows PowerShell recognizes the opening parameter block, and treat a missing target release as the expected pre-publication state. Publishing logic is unchanged. The unmodified original updater is retained in updater-original.zip for comparison. Publication has not been run here.

Before publication: run the Windows/Spotify checklist in TEST38_NOTES.md. Do not equate successful build/CI with full GUI or account testing. The existing Windows updater, not the obsolete Bash prerelease script, is the intended publishing path for this package.
