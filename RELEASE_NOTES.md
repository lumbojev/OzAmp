# OzAmp 1.0.0

OzAmp 1.0.0 is the first public release of the native Windows audio player created by Oskar Lumbojev.

The release consolidates the stabilized 3.5.x development line into the first public version. It includes local playback, a dockable playlist, queue management, persistent EQ presets, session restore, selectable audio devices, media-key support, local library tools, album art, track information, skins and a fullscreen audio-reactive visualizer.

## Release highlights

- Native C++ / Win32 interface
- WASAPI audio output and Windows Media Foundation decoding
- Searchable, resizable playlist with magnetic alignment
- Play Next and ordered queue
- Persistent 10-band EQ presets
- Session and window restore
- Media keys and audio-device fallback
- Local media library and metadata panels
- Fullscreen visualizer with a fixed OzAmp color palette
- `.ozskin` theme support
- Local-first operation with no account, telemetry or analytics
