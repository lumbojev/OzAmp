# OzAmp 1.0.0 feature overview

- Native C++ / Win32 desktop player
- WASAPI audio output with selectable devices
- Windows Media Foundation decoding
- Persistent 10-band EQ and presets
- Playlist filtering, multiselect, drag/reorder and resize
- Right-edge playlist magnet/docking behavior
- Play Next / queue workflow
- Session restore
- Global media hotkeys
- Local media library
- Album art and track metadata panels
- Fullscreen audio-reactive visualizer
- Shade / compact player mode
- Custom `.ozskin` themes
- Local-first operation with no telemetry
