# OzAmp 1.0.0

The first public release of **OzAmp**, a native Windows audio player created by **Oskar Lumbojev**.

OzAmp is focused on fast local playback, a compact custom interface and the kind of direct desktop-player workflow that stays out of the way of the music.

## Highlights

- Native C++ / Win32 application
- WASAPI audio output
- Windows Media Foundation decoding
- Dockable and resizable playlist with search/filter
- Play Next and ordered queue
- Persistent 10-band EQ presets
- Session restore
- Hardware media-key support
- Selectable audio devices with fallback handling
- Local media library, album art and track information
- Fullscreen audio-reactive visualizer
- Compact shade mode
- `.ozskin` themes
- No account requirement, telemetry or analytics
